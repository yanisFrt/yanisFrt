### 👋 About me

I build **offline-first desktop software and SaaS products** that run real businesses.
8 years in production software, founder and technical lead of [**Codes Nova**](https://www.codesnova.com) (team of 4, since 2020).

- 🦀 **Desktop systems in Rust + Tauri v2**: offline-first architectures on SQLite, hardware integration (thermal printers, barcode scanners, IP cameras), sub-200 ms receipt printing pipeline
- 🗄️ **Backend & data**: PostgreSQL, SQLite, Neo4j graph models, REST APIs, sync and multi-tenant design
- 🤖 **Agentic AI engineering**: multi-agent coding workflows, spec-driven development with coordinated agents, LLM orchestration and retrieval over graph data
- 🎓 M.Sc. Networks & Distributed Systems (USTHB)
